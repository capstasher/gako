The first proper release of **GAKO**, the GIMP Android Kanvas Operator: GIMP's own image engine
(GEGL and babl) on Android, with a touch interface built for one hand. GAKO is now a layered editor
with GIMP's tools, and it opens and saves GIMP's own `.xcf` files.

## Highlights

**Layers, the GIMP way**
- Layered documents with groups, masks, opacity, visibility and lock alpha
- All 33 of GIMP's layer modes, composited with GIMP 3's own formulas, so images look as they do in
  GIMP (checked against GIMP 3.2)
- Undo History for everything; layers of any size, anywhere on the canvas

**Tools** (one finger uses the tool, two fingers pan, zoom and turn the view)
- Paint: brush, pencil, airbrush, eraser, clone, heal, smudge, blur, dodge/burn, fill, gradient,
  symmetry, brush presets and stylus pressure
- Text: re-editable text layers, any installed or imported font; GIMP's text layers open as editable text
- Select: rectangle, ellipse, lasso, selection brush, fuzzy, by colour, **Foreground Select**,
  **Quick Mask**, channels
- Paths, move, unified/perspective transform, **crop**, **Warp Transform**, Measure with Straighten
- Cut, copy and paste (including Android's clipboard), Layer via Copy/Cut, Stroke Selection
- **Filter Brush**: paint any of ~200 GEGL filters onto just the area you brush

**Colours and filters**
- GIMP 3's own colour tools (Brightness-Contrast, Hue-Saturation, Color Balance, Colorize, Threshold,
  Posterize, Desaturate), Curves and Levels, plus ~200 GEGL filters with live previews
- Filters, Curves and Levels respect the selection; Repeat Last and Recently Used

**Files**
- Save and open **XCF** (layers, masks, groups, paths, GIMP 3 layer effects; anything GAKO doesn't
  edit is kept on the way back), **PSD/PSB** with layers, and OpenRaster
- Export to PNG, JPEG, WebP, HEIF, TIFF, GIF, BMP, TGA, ICO, PPM, ORA and layered PSD
- Take a photo straight into GAKO; EXIF carries over to exports (location only if you ask)
- Unsaved work survives Android closing the app; the start screen lists recent images

**Phone-first**
- GIMP's menus along the bottom edge, nested for thumbs; a side rail and Layers dock on wide screens
- Two-finger tap to undo, three-finger tap to redo; palm rejection once you use a pen
- GIMP's keyboard shortcuts on hardware keyboards

## Installing

Download `gako-0.3.0-arm64.apk` below and open it on your phone (Android 12 or newer, 64-bit ARM).

**If you had a dev build:** uninstall it first. Releases are signed with GAKO's new release key, so
Android won't install this over an old dev build. Save any open work as XCF before you do, because
uninstalling clears GAKO's recent-images list and recovery file. Later releases will update in place.

## Known limits

- Images are capped at 24 megapixels for now (bigger photos open scaled down)
- Groups can't have masks; filters and painting work on layers, not groups
- GIMP 3 layer effects are applied when a file opens and become part of the layer
